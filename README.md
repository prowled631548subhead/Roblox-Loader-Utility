## FAQ

### What is XCutors?

XCutors is a curated Windows desktop package that bundles several popular Roblox script executors (Volt, Synapse Z, Potassium, Wave) with a universal loader for convenient management and execution of Lua scripts.

### Is XCutors safe to download and use?

XCutors itself is a clean launcher. The included third-party executors are maintained by their respective developers. Always download from the official source and use at your own discretion, being aware of Roblox's Terms of Service.

### How do I update the executors?

Updates for individual executors are managed by their developers. The XCutors package will periodically release new versions with the latest stable builds. Check the GitHub releases page for updates.

### Can I use XCutors on macOS or Linux?

No, XCutors is currently developed and supported exclusively for Windows desktop operating systems.

### Do I need a key or license for the executors?

Some of the bundled executors may require a separate key or license purchased from their official developers. XCutors is the management package and does not provide or sell keys for these third-party tools.

### Why isn't my script working?

Script functionality depends on the executor's compatibility with the current Roblox version and the script's own code. Ensure your chosen executor is up-to-date and check the script's documentation for requirements.

### How do I report a bug with the XCutors loader?

Please open an issue on the official GitHub repository with a detailed description, including steps to reproduce, your Windows version, and any error messages.

### Is there a command-line interface available?

The primary interface is the GUI (xcutorsLoader.exe). Advanced command-line options for automation are not currently implemented but may be considered for future releases.

### Can I add custom executors to the loader?

The XCutors loader is configured to recognize and manage the five bundled executors. Adding unsupported third-party executables is not officially supported and may cause instability.
